# Mecanismo PAN-TILT

En esta carpeta se documenta el desarrollo físico del mecanismo PAN-TILT correspondiente al Frente A.

El sistema fue fabricado mediante impresión 3D e integra la carcasa de la ESP32-CAM, el soporte de inclinación y el mecanismo de giro mediante servomotores.

## Evidencias

Las imágenes incluidas muestran distintas etapas del montaje:

- Ensamble inicial de la estructura PAN-TILT.
- Pruebas de ajuste de la carcasa impresa.
- Elementos complementarios de la estructura.
- Integración física del módulo láser/emisor.

Estas pruebas permitieron verificar dimensiones, puntos de montaje y compatibilidad mecánica antes de realizar la integración electrónica definitiva.
